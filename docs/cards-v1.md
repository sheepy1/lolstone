# 初始卡池 v1

配合 [spec.md](spec.md) 使用。规则和关键词定义以 spec 为准，这里只列卡。

读法：

- 身材写成"攻击/生命"。
- 需要玩家选目标的效果写"一个……"，自动选的写"所有……"或"随机……"。
- 没写"敌方"或"友方"的目标，双方都能选。
- 英雄列有 Data Dragon 的 key，拉美术用。

数量：中立 24 张，德玛西亚 16 张，诺克萨斯 14 张，艾欧尼亚 16 张，弗雷尔卓德 16 张，共 86 张，外加 9 个衍生物。

## 规则备注

几张卡在规则边角上的处理，都已写进 spec，这里集中列一下方便实现时对照：

- 泰达米尔的无尽怒火只拦伤害导致的死亡。剧毒（提莫、魔沼蛙、薇恩）、消灭（德玛西亚正义、处决）和减益（特朗德尔的 -2/-2 把受伤的他减到 0 血）都能直接杀死他。沉默会移除这个效果。
- 暴风雪打死虚空幼虫时，亡语召唤出来的蠕虫不会被同一张暴风雪冻结：死亡结算在整个效果执行完之后才做，见 spec 2.6。
- 弗拉基米尔的吸血、提莫和魔沼蛙的剧毒，对攻击和自身效果造成的伤害都生效。
- 李青、传送回城把随从移回手牌时手牌已满，该随从直接销毁，不触发亡语。
- 奎因、劫、嘉文四世的战吼召唤放在本随从右边；克烈、赛恩、虚空幼虫、艾尼维亚的亡语召唤放在死者原来的位置；召集放在最右边。
- 易消灭随从后再次攻击，不受风怒那样的次数上限限制，杀一个就能再打一次。
- 科加斯和易的"消灭"包括被攻击时反杀，也包括剧毒致死；被法术打死的不算。

## 平衡调整记录

2026-10-19，M2 收尾，代码在 main 的 12c6d1c：

- 原因：M2 的验收要求四套预组 L1 对 L1 互打，每个职业组合的胜率都在 30% 到 70% 之间。AI 修完之后只剩艾欧尼亚对弗雷尔卓德不达标，28.4%，每组 500 局。
- 改动：凯南 2/2 改 2/3，费用和文本不变。阿卡丽 2/2 改 2/3 原本一起改，但按 spec 3.7"身材按 LoL 定位"，刺客不该加血，这项撤回；替代方案阿卡丽 3/2 已随定位核查一起采纳，见下一条。
- 结果：凯南 2/3 加阿卡丽 2/3 一起测时，每个组合的胜率都落在 33% 到 67% 之间，换了四批种子各跑一遍都达标，艾欧尼亚对弗雷尔卓德为 34.6% 到 36.4%。阿卡丽撤回后这组数据作废，要按新方案重测。
- 凯南 2/3 比 spec 3.6 的身材基准多 1 点生命，是为平衡故意的，不是笔误。
- 备选方案没采用：阿卡丽 2/3 加易 5/5。

2026-10-19，定位核查（spec 3.7），用户确认全部采纳：

- 原因：用户要求英雄随从的攻血分配符合它在 LoL 里的定位，例如易是刺客，血量不该高。
- 改动：17 张卡攻血重分、1 张换关键词，总身材基本不变，明细见"定位核查表"：雷克塞 4/5 并把嘲讽改成突袭、科加斯 4/7、薇恩 2/1、波比 1/4、奎因 3/2、凯尔 6/4、安妮 1/2、德莱文 4/2、卡特琳娜 4/2、赛恩 3/7、阿卡丽 3/2、易 5/3、瑟庄妮 3/6、努努和威朗普 3/7；补查战士细分后追加菲奥娜 4/3、克烈 3/2、永恩 5/4。
- 结果：代码已同步，main 上 29b4d02 的 18 张卡和这张表一致。重测后艾欧尼亚达标，但诺克萨斯变弱，弗雷尔卓德对诺克萨斯 73.4%（种子 20000），处理见下一条。

2026-10-19，定位调整后的追加，用户已定：

- 原因：18 张卡按定位改完后，艾欧尼亚达标，但诺克萨斯变弱，弗雷尔卓德对诺克萨斯 73.4%（种子 20000）。德莱文、卡特琳娜改成更脆的身材后，快攻打不过弗雷尔卓德加厚的坦克。
- 改动：泰隆 3/2 改 4/2，莎弥拉 5/4 改 6/4，费用、文本、关键词不变。两张都只加攻击，符合 spec 3.7 刺客和射手的平衡方向。

## 卡牌 id 规则
