# M4 分镜表

配合 [spec.md](spec.md) 的 5.3、5.5、5.6、5.8 使用。5.6 给了每个事件的时长和一句话画面，这里把每一行展开成可以直接照着做的分镜。
多个会话并行做时，先把第 1 节的约定读完再做自己那几行；约定不能各自发挥，否则做出来不是一个风格。
招牌卡的专属特效在 [m4-signature-fx.md](m4-signature-fx.md)，新玩家前几分钟的验收在 [m4-first-minutes.md](m4-first-minutes.md)。

## 1. 约定

### 1.1 一个事件的骨架

每个事件都由同样的几段组成，哪一段没有就写"无"，不要省略：

1. 起手：动作前的小幅反向运动或停顿，让玩家知道要发生什么。
2. 出手：主运动，整个事件里最快的一段。
3. 命中帧：整个事件的同步点。画面撞击、声音的瞬态、震屏、飘字、数值跳变全部落在这一帧。差一两帧玩家说不出哪里不对，但会觉得"软"。
4. 收尾：回弹、残留粒子、淡出。
5. 常驻：事件结束后留在场上的状态（冰层、护盾环、buff 图标、裂纹）。

### 1.2 分量

"分量"指一个时刻叠加了多少反馈通道、每个通道多强，和时长无关。通道有八个：位移、形变、粒子、闪光、震屏、声音瞬态、语音、飘字。

| 档 | 通道数 | 震屏 | 例子 |
| --- | --- | --- | --- |
| 轻 | 1 到 2 | 无 | 按钮、抽牌、法力变化、增益 |
| 中 | 3 到 4 | 最多 S1 | 出随从、攻击命中、随从死亡、冻结 |
| 重 | 5 以上 | S2 或 S3，外加画面级反馈 | 群体法术、英雄受重伤、胜负、招牌卡 |

每个事件标了档位。做完数一遍通道：不够就是软，超了就是吵。"对标炉石"指的是这一刻的档位和节奏，不是外观。

### 1.3 时长与缓动

时长写毫秒。缓动只用下面这几个 GSAP 名字，不自创：

| 代号 | GSAP | 用途 |
| --- | --- | --- |
| 起 | power3.in | 蓄力、起跳、加速离开 |
| 落 | power2.out | 落位、停下、滑到新槽位 |
| 弹 | back.out(1.4) | 落位后的小回弹 |
| 砸 | expo.in 接 elastic.out(1, 0.45) | 砸落、压扁回弹 |
| 飘 | 出现 power2.out，消失 power1.in | 飘字、图标出现和消失 |
| 脉 | sine.inOut，yoyo 循环 | 常驻脉动：结束回合按钮、低血闪烁 |
| 线 | none | 匀速，只用于飞弹和粒子的中段 |

尺寸单位：底座高（场上随从底座的高度）、卡高（手牌一张卡的高度）、槽距（相邻两个槽位中心的距离）。写"抬 0.3 底座高"而不是像素。

### 1.4 镜头与屏幕反馈

镜头固定，屏幕反馈只有三种：

- 震屏 S1 / S2 / S3：相机位置叠加衰减噪声。S1 幅度 0.3% 画面高、120ms；S2 0.8%、200ms；S3 1.5%、320ms 并带 60ms 白闪 15%。同一帧多个震屏取最大，不叠加。
- 边缘泛红：四边径向红色晕影，0 到 35% 透明度，100ms 进、400ms 出。只给我方英雄受重伤。
- 棋盘闪：全屏加色层，颜色按 fx 类型，80ms 到峰值 12%，再 200ms 淡出。给群体法术和招牌卡；火焰单体法术也闪，峰值减半到 6%。

频率限制：S2 以上每回合不超过 3 次，同一秒内不重复；超出的降一档。

| spark_light / spark_heavy | 轻 / 重撞击火花 |
| fire_bolt | 火焰飞弹（带拖尾，color 可覆盖，冰箭、灵魄都是它的变体） |
| frost_spread | 冰霜扩散 |
| ice_shatter | 冰晶碎裂 |
| holy_pillar | 圣光光柱 |
| shadow_gather | 暗影聚拢 |
| slash_trail | 挥砍残影 |
| shield_break | 护盾碎裂 |
| death_shards | 死亡碎片（带重力） |
| heal_motes | 治疗光点（上升） |
| buff_ring | 增益金环 |
| stealth_smoke | 潜行烟雾 |
| summon_gather | 召唤凝聚（向内） |

参数约定：count 数量，dir 方向（up / out / in / toward:目标），color 覆盖主色，scale 缩放。不写就用预设默认。所有预设受 5.10 的粒子总量上限约束，超出时不生成。

### 1.6 声音层

层：ui、action（动作：挥击、冲刺、飞行）、impact（材质：命中、碎裂、结冰、落地）、magic（法术元素）、voice、music、ambient。触发时刻写成"impact 在 t=命中帧"。

- 中档以上的事件至少两层，命中帧必有 impact 层。
- 动作层的声音比命中帧早 40 到 60ms 开始，让瞬态刚好落在命中帧。
- voice 比画面晚 100 到 150ms，不抢命中帧；同一时刻只播一条，新的打断旧的；语音播放时 music 和 ambient 压低 6dB。
- 命中声分轻重：伤害 ≤ 2 轻，≥ 3 重，≥ 5 再叠一层低频。
- 响度统一走 normalize 管线，分镜里不写音量。

### 1.7 并行

同一个 group 的事件：

- 一起开始，按目标从左到右每个错开 40ms，形成一道波；最后一个结束算整组结束。
- 一组里最多一次震屏，取最重的那次；棋盘闪只闪一次。
- 一组里的语音只播一条，死亡语音播最后一个死的。

不同 group 串行：上一组最后一个事件的收尾进行到 60% 时，下一组就开始。收尾可以重叠，命中帧不能重叠。这是必做项，不是可选：对手回合的时长口径（spec 4.2）靠它，预计省 15% 到 25%。

法力变化（E25）永远和引起它的事件并行，不单独占队列时间；对手出牌扣法力也一样。

### 1.8 颜色

伤害红 #ff3b30，治疗绿 #3ddc84，护盾白 #f2f6ff，增益金 #ffc44d，减益紫 #b05cff，冰 #8fd8ff，火 #ff7a1a，光 #fff1b8，影 #6b3fa0，物理 #d9d9d9。飘字 2px 深色描边，字号三档：≤ 2 小、3 到 4 中、≥ 5 大。

## 2. 交互手感参数

不是事件，但纵切片第一步就要用，参数统一在这里。

- 手牌扇形：圆心在手牌区下方 2.2 卡高处；张数 ≤ 5 时间距 0.55 卡宽，10 张时 0.32 卡宽，线性插值；每张沿圆心倾斜。
- 悬停：120ms 落，抬 0.15 卡高、放大 1.12、倾角减半、略转正；邻牌各让 0.12 卡宽；离开 150ms 落回。
- 拿起：按下 80ms 内卡牌离开台面 0.25 卡高（起），阴影随之扩大变淡。
- 拖拽跟随：阻尼弹簧，角频率 6Hz、阻尼比 0.7；卡牌落后鼠标最多 0.3 卡宽。倾角按速度：每 1 卡宽/秒 倾 6°，上限 18°，向运动方向倾；停下 200ms 内回正（弹）。
- 松手回手牌：300ms 落 飞回槽位，落位弹。
- 松手上场：走 E07。
- 目标箭头：从来源出发的三次贝塞尔，控制点抬高 0.8 底座高，箭头头部先到、身体后补（150ms 落）；颜色伤害红；箭尾跟随鼠标用同一组弹簧参数。合法目标出现红色准星，脉 0.8s 周期；非法目标变暗 40%。
- 能出的牌：绿色自发光边 脉 1.6s 周期；费用不够 变暗 35%。能攻击的随从：底座绿色自发光描边 脉 1.6s。
- 快进：按住空格或点击棋盘，时间线 timeScale 3，松开恢复。

### E10 群体法术 · 800ms + 600ms · 重

前三段同 E09。效果：同时落到所有目标，按 1.7 错开 40ms 成波；棋盘闪 fx 色 12%；S2。每个目标的 damage / freeze 事件同组，在各自的命中帧开始。
粒子：按 fx，count 乘目标数但总量不超过 5.10 上限。声音：magic 大法术音在溶解 t=0；impact 只播一次，取重。镜头：S2 加棋盘闪。
分量：重。全场一震的感觉来自画面级闪光、重音、全部目标同时反馈三件事同时发生，不是粒子更多。

### E27 AI 思考 · 时长见 spec 4.2 的 AI_PACE 规则 · 轻

时长由对局层的 AI_PACE 决定：同一回合第一个动作前 0.8 到 1.5s，之后每个乘 0.6、最短 0.4s，±15%，结束回合前 0.2s。画面：对手手牌里随机一张抬起 0.3 卡高、倾角 -8°（250ms 落），停到时长结束前 200ms，放下 200ms 落；时长超过 1s 时三成概率先抬另一张放下、再抬要打出的那张；要打出的那张抬起后不放下，直接飞出进入 E06；时长不足 0.6s 时只抬不停。不发声。
衔接：抬起的那张若正是要打出的，直接从抬起状态飞出进入 E06。
分量：轻。它的作用是节奏，不是反馈；一回合里 AI 每个动作前都要有，但时长随机，不然像机器。
