# 初始卡池 v1

配合 [spec.md](spec.md) 使用。规则和关键词定义以 spec 为准，这里只列卡。

读法：

- 身材写成"攻击/生命"。
- 需要玩家选目标的效果写"一个……"，自动选的写"所有……"或"随机……"。
- 没写"敌方"或"友方"的目标，双方都能选。
- 英雄列有 Data Dragon 的 key，拉美术用。

数量：中立 24 张，德玛西亚 16 张，诺克萨斯 14 张，艾欧尼亚 16 张，弗雷尔卓德 16 张，共 86 张，外加 9 个衍生物。

## 规则备注

几张卡在规则边角上的处理，都已写进 spec，这里集中列一下方便实现时对照：

- 泰达米尔的无尽怒火只拦伤害导致的死亡。剧毒（提莫、魔沼蛙、薇恩）和消灭（德玛西亚正义、处决）能直接杀死他。沉默会移除这个效果。
- 李青、传送回城把随从移回手牌时手牌已满，该随从直接销毁，不触发亡语。
- 奎因、劫、嘉文四世的战吼召唤放在本随从右边；克烈、赛恩、虚空幼虫、艾尼维亚的亡语召唤放在死者原来的位置；召集放在最右边。
- 易消灭随从后再次攻击，不受风怒那样的次数上限限制，杀一个就能再打一次。
- 科加斯和易的"消灭"包括被攻击时反杀，也包括剧毒致死；被法术打死的不算。

## 实现分级

引擎按这个顺序做，A 级做完就能跑通整个对局流程。

A 级，只有身材和关键词，不需要效果系统：
近战小兵、远程小兵、提莫、石甲虫、魔狼、魔沼蛙、蓝色哨兵、卡兹克、炮车、雷克塞、峡谷先锋、超级兵、薇恩、波比、赵信、加里奥、泰隆、德莱文、弗拉基米尔、莎弥拉、凯南、亚索、艾瑞莉娅、布隆、努努和威朗普、奥恩。

B 级，用 spec 3.4 的效果模型描述，不写代码：
其余所有卡。其中回合触发的有娑娜、斯维因、纳什男爵、冰凤凰蛋；消灭触发的有科加斯（on_kill 加 buff）和易（on_kill 加 extra_attack）；连击的有阿卡丽、李青；激怒的有奥拉夫；用随机关键词动作的有乌迪尔。

C 级，需要脚本：

| 卡 | 为什么模型写不出来 |
| --- | --- |
| 菲奥娜 | 改攻击结算规则：攻击时不吃反击伤害 |
| 泰达米尔 | 致命伤害替代效果，要在死亡判定前拦一下，并且只触发一次 |

## 卡牌 id 规则

`<职业>.<英文名小写>`，职业取 neutral、demacia、noxus、ionia、freljord。英雄用 Data Dragon key 的小写，例如 `demacia.jarvaniv`、`ionia.masteryi`。非英雄用英文名，例如 `neutral.melee_minion`、`neutral.baron_nashor`。衍生物加 `token.` 前缀，例如 `token.demacian_soldier`。法力药水是 `token.mana_potion`。
