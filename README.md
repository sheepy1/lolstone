# LoLstone

网页版的卡牌对战游戏：规则对齐《炉石传说》的基础模式，卡牌角色换成《英雄联盟》的英雄，对局画面是 Three.js 做的真 3D 棋盘。单机，和 AI 对战，浏览器里打开就能玩。

## 玩法

- **规则**：英雄 30 点生命，法力水晶每回合加一、上限 10，场上最多 7 个随从，手牌上限 10 张，牌库抽空就疲劳。开局可以换牌，后手多一张「法力药水」。
- **职业**：按《英雄联盟》的地区分四个职业，各有一位英雄和一个 2 费英雄技能。

| 地区 | 英雄 | 英雄技能 | 风格 |
| --- | --- | --- | --- |
| 德玛西亚 | 盖伦 | 召集：召唤一个 1/1 的德玛西亚士兵 | 铺场、增益、嘲讽、圣盾 |
| 诺克萨斯 | 德莱厄斯 | 诺克萨斯断头台：对敌方英雄造成 2 点伤害 | 快攻、直伤、吸血 |
| 艾欧尼亚 | 阿狸 | 灵魄：造成 1 点伤害 | 法术、潜行、连击、回手 |
| 弗雷尔卓德 | 艾希 | 寒冰箭：冻结一个敌方随从 | 冻结、大体型、嘲讽、法力加速 |

- **卡池**：86 张可收集的卡和 9 种衍生物。随从全是英雄，中立卡是峡谷里的小兵、野怪、亚龙、虚空生物和约德尔人。关键词八个：嘲讽、冲锋、突袭、圣盾、潜行、风怒、吸血、剧毒；效果有战吼、亡语、连击、回合开始和回合结束触发。卡牌全部用数据描述，加一张常规卡只改数据文件。
- **AI**：三档。新手随手出牌；标准会算斩杀、做划算的交换；困难会规划整个回合，并防着你下回合的反扑，搜索放在 Web Worker 里不卡画面。
- **卡组**：四套预组开箱即用，也可以在卡组编辑器里自组，存在浏览器本地。
- **视听**：每个事件有自己的动画和音效，有音乐、环境音，英雄有登场和阵亡语音，招牌卡有专属特效。目标是不看规则，光看画面和听声音就知道场上发生了什么。

## 操作

- 拖一张随从牌到场上就是出牌；法术牌拖出手牌区进入施法状态，拖到目标上松手。
- 需要选目标时从来源拉出箭头，合法目标高亮；右键或拖回原位取消。
- 按住能攻击的随从拉出攻击箭头，松手就攻击。
- 点击棋盘或按空格把当前动画加速到三倍；Esc 打开对局菜单，里面有设置、认输和回主菜单。
- 悬停场上的随从或对手打出的牌，左侧显示完整卡面和关键词解释。

## 本地运行

需要 Node 22 以上和 pnpm。美术、语音、音效都在仓库里，克隆下来直接能玩。

```bash
pnpm install
pnpm dev        # 开发服务器，打开终端里打印的地址
pnpm build      # 生产构建，产物在 dist/
```

地址带 `?mute=1` 静音，带 `?replay` 观看一局固定种子的回放。

```bash
pnpm test          # 单元测试
pnpm typecheck     # 类型检查
pnpm play          # 命令行里和 AI 打一局
pnpm arena         # AI 互打统计，例：pnpm arena --a l1 --b l2 --games 250
```

## 技术

- **引擎**是纯 TypeScript，不依赖 DOM：局面是纯数据，所有随机数来自种子，同一局面加同一动作结果一定相同；每个动作返回一串事件，表现层只靠事件演出。命令行对局、测试和 AI 模拟用的是同一份规则。
- **表现层**用 Three.js 做场景和光照，GSAP 编排动画，React 只画菜单、卡组编辑这类文字界面，Howler 放声音。显示局面落后于真实局面，动画播完才追上，玩家看到的和能操作的始终一致。
- **目录**：`src/engine` 规则引擎，`src/cards` 卡牌数据，`src/ai` 三档 AI，`src/presentation` 导演、显示局面和动画，`src/scene` Three.js 物体和输入，`src/ui` React 界面，`src/audio` 音频，`scripts` 素材抓取和处理。
- **测试**六百多个，覆盖每个关键词、每张卡、换牌、事件完整性和 AI 互打冒烟。

## 素材与版权

- 英雄头像、原画和语音来自 Riot Games 的 Data Dragon 和 CommunityDragon，部分卡面原画来自《符文之地传说》。《英雄联盟》《符文之地传说》及这些素材的版权归 Riot Games 所有。本项目是非商业的个人作品，与 Riot Games 没有关联，也未经其背书。
- 规则参考《炉石传说》，那是暴雪娱乐的作品和商标，本项目与暴雪没有关联。
- 音效和音乐只收 CC0 授权的素材，每一条的来源和授权记在 `scripts/data/audio-sources.json`。
- 字体按各自的开源许可证使用，见 `public/fonts/OFL.txt`。

## 部署

纯静态站点：`pnpm build` 出 `dist/`，任何能克隆仓库、跑 `pnpm install --frozen-lockfile --prod=false` 和 `pnpm run build`、托管 `dist/` 的平台都能部署，pnpm 版本按 `package.json` 的 `packageManager`。`/assets/` 下的文件名带内容哈希，可以长期缓存；美术和音频文件改了内容但没改名时，发布后浏览器可能要强制刷新。
